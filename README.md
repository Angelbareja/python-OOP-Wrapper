# 👨‍💼 Employee Management System

A **Python Object-Oriented Programming (OOP)** project that simulates a simple Employee Management System. This application allows users to create and manage **Person**, **Employee**, and **Manager** records through a menu-driven console interface.

---

## 📌 Project Overview

This project demonstrates the fundamentals of Object-Oriented Programming in Python by creating different types of employee records and displaying their information through a simple command-line interface.

It is designed for beginners to understand how classes, constructors, objects, and user interaction work together in Python.

---

## ✨ Features

* 👤 Create a Person
* 💼 Create an Employee
* 👨‍💼 Create a Manager
* 📋 Display stored details
* 🖥️ Menu-driven console interface
* 🚪 Exit the application safely

---

## 🛠️ Technologies Used
